Bienvenue sur mon portfolio interactif ! Ce projet est bien plus qu'un simple site vitrine : c'est une expérience immersive simulant un système d'exploitation (**Aincrad OS**) avec deux environnements distincts : **Windows 11** (Portfolio & Apps) et **Ubuntu Linux** (CV & Documents).

👉 **Accéder au Portfolio :** [https://mateo-padoan.netlify.app/](https://mateo-padoan.netlify.app/)

## 🚀 Fonctionnalités par Environnement

### 🪟 Mode Windows 11 : L'Expérience Interactive
C'est ici que se trouve le cœur de mon portfolio. Une fois booté dans cet environnement, vous aurez accès à :

#### 1. Présentation & Dashboard
*   **À Propos :** Une présentation détaillée de mon parcours, mes compétences techniques (Développement, Électronique, IoT, etc.), mes centres d'intérêt et ma disponibilité.
*   **Dashboard :** Un tableau de bord dynamique affichant l'heure en temps réel, ainsi que des informations système simulées ou réelles (état de la batterie, réseau, etc.).

#### 2. Applications Intégrées
J'ai développé plusieurs applications natives intégrées directement dans l'interface :

*   **♟️ Gomoku AI (Puissance 5)**
    *   Un jeu de stratégie inspiré du Go, joué sur un Goban 19x19.
    *   **Objectif :** Aligner 5 pierres avant votre adversaire.
    *   **Mode :** Actuellement disponible en mode **Solo contre l'IA**.
    *   **Conseil :** Si vous ne pouvez pas gagner, essayez au moins de bloquer l'adversaire ! Les coups sont possibles horizontalement, verticalement et en diagonale.
    *   *Note :* Le mode multijoueur en ligne est prévu pour fin juin 2026.

*   **💻 Terminal Web Linux**
    *   Un terminal Linux fonctionnel recréé entièrement en React.
    *   Tapez `help` pour voir la liste des commandes disponibles (`ls`, `cd`, `cat`, `nano`, etc.).
    *   Vous pouvez naviguer dans un système de fichiers virtuel, lire et modifier des fichiers.

*   **⌨️ Éditeur de Code (VS Code Lite)**
    *   Une alternative légère à VS Code intégrée au navigateur.
    *   Supporte actuellement **JavaScript** et **TypeScript**.
    *   Exécution directe du code dans la console intégrée.
    *   *En cours de développement :* Support pour d'autres langages backend/frontend.

*   **🧮 Calculatrice Scientifique**
    *   Une calculatrice puissante capable de gérer des expressions complexes.
    *   **Syntaxe flexible :** Vous pouvez omettre les opérateurs implicites (ex: `8(7)` est équivalent à `8*7`).
    *   **Mode Graphique :** Visualisez les courbes de fonctions mathématiques en temps réel.

*   **🎵 Lecteur Musical (SoundCloud Integrated)**
    *   Un lecteur audio intégré permettant d'écouter de la musique classée par style (Trance, Techno, Hardcore, Ambient, Aléatoire).
    *   Sélectionnez un genre et laissez la plateforme vous proposer des titres.
    *   *Fonctionnalité future :* Possibilité d'ajouter ses propres playlists.

## 🛠️ Technologies Utilisées

Ce projet a été construit avec une stack moderne et performante :

*   **Frontend :** React + TypeScript + Vite
*   **Styling :** Tailwind CSS
*   **Éditeur de Code :** Monaco Editor (le moteur de VS Code)
*   **Terminal :** Xterm.js
*   **Graphiques :** Chart.js / React-Chartjs-2
*   **Calculs Mathématiques :** Math.js
*   **Icônes :** React Icons
*   **Hébergement :** Netlify

## 📦 Installation Locale

Si vous souhaitez cloner et lancer le projet localement :

```bash
# Cloner le dépôt
git clone https://github.com/Mateo79/portfolio.git
cd portfolio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```
